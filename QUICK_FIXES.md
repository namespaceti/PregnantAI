## ⚡ Частые проблемы и мгновенные решения

### 1. "Съехали" стрелки и текст навигации
**Симптом:** Элементы навигации отображаются неправильно
**Решение:** Добавить в styles раздел:
```typescript
headerSpacer: { width: 40 },
weekNavigation: { flexDirection: 'row', alignItems: 'center', justifyContent: 'space-between' },
weekNavButton: { width: 32, height: 32, backgroundColor: '#f9fafb', borderRadius: 16, alignItems: 'center', justifyContent: 'center', elevation: 1 },
weekInfo: { alignItems: 'center', flex: 1, marginHorizontal: 16 },
```

### 2. Ошибка "No data found for week X"  
**Симптом:** Красная ошибка на экране
**Причина:** В pregnancyData.json отсутствуют данные для недели
**Решение:** Проверить массив `pregnancyWeeks` в JSON файле

### 3. Приложение крашится при запуске
**Решение по порядку:**
1. `npm start -- --reset-cache`  
2. Проверить синтаксис pregnancyData.json
3. Проверить импорты в CalendarScreen.tsx
4. Перезапустить Metro: Ctrl+C → npm start

### 4. Стили не применяются
**Проверить:**
- Нет опечаток в названиях стилей
- Все стили определены в StyleSheet.create()
- Правильная структура: `style={styles.название}`

## 🚀 Алгоритм быстрого исправления

1. **Читай ошибку в консоли** 📖
2. **Найди файл и строку** 🔍  
3. **Проверь синтаксис** ✅
4. **Сравни с working версией** 🔄
5. **Тестируй на разных неделях** 🧪

## SOS - Если ничего не помогает

1. Сохрани изменения
2. `git stash` (если используешь git)
3. Верни последнюю рабочую версию
4. Применяй изменения по одному
5. Тестируй после каждого изменения

**Главное правило:** Одно изменение → один тест → коммит
