# 📊 Структура данных pregnancyData.json

## 🔍 Обзор файла данных

**Местоположение:** `app/mobile/assets/images/pregnancyData.json`  
**Размер:** ~42 объекта недель + справочные данные  
**Кодировка:** UTF-8  
**Формат:** JSON

---

## 🗂️ Основная структура

```json
{
  "pregnancyWeeks": [ ... ],      // Массив 42 недель
  "nutritionByTrimester": { ... }, // Питание по триместрам  
  "activityByTrimester": { ... }   // Активность по триместрам
}
```

## ⚠️ Важные правила при редактировании

### ✅ МОЖНО:
- Добавлять новые поля в объекты
- Изменять текстовое содержимое
- Обновлять массивы симптомов/советов
- Корректировать физические данные

### ❌ НЕЛЬЗЯ:
- Менять структуру ключей объекта
- Удалять обязательные поля  
- Нарушать последовательность недель (1-42)
- Использовать невалидные цвета/иконки

### 🔍 Валидация данных:
```typescript
// Обязательные поля для каждой недели:
week: number (1-42)
babySize: { lengthCm, weightGrams, fruitComparison, fruitEmoji, iconName, cardColor }
development: { mainFocus, brainSystem, respiratorySystem, movementSystem, growthSystem, weekMilestones }
momChanges: { mainBodyChange, bellyCircumference, specificSymptoms, weeklyBodyChanges, dailyTasks, weeklyChecklist }
```
